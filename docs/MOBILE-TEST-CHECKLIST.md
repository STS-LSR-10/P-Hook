## 0.3) สรุปเป็นการ์ด (ทุกแพ็กเกจ)

- [ ] พิมพ์ `สรุปวันนี้` → ได้การ์ดสรุป (หัวข้อ "สรุปวันนี้" + วันที่ พ.ศ.) รายรับ/รายจ่าย/เหลือ ตรงกับรายการของวันนี้ และไม่มีบรรทัดเทียบกับเมื่อวาน
- [ ] พิมพ์ `สรุปเดือนนี้` → การ์ดตามรอบงบ มีหมวดสูงสุด และบรรทัด "เพิ่มขึ้น/ลดลง % จากเดือนก่อน" (ถ้าเดือนก่อนมีรายจ่าย) ตัวเลขตรงกับหน้า "สรุป" ใน LIFF
- [ ] กดปุ่ม "ดูรายละเอียด" เปิดหน้าสรุปใน LINE ได้
- [ ] วัน/เดือนที่ยังไม่มีรายการ → ได้ข้อความสั้นๆ ว่ายังไม่มีรายการ
- [ ] การ์ดสรุปอัตโนมัติ (สัปดาห์/เดือน) ยังหน้าตาเหมือนเดิม

## 0.28) หมวดของตัวเอง + อีโมจิ (สร้าง/แก้ = Pro ขึ้นไป)

- [ ] Pro/Elite: หน้า "หมวด/งบ" → "เพิ่มหมวด" → เลือกอีโมจิจากตาราง (หรือพิมพ์อีโมจิจากคีย์บอร์ดมือถือเอง) → บันทึก แถวหมวดมีอีโมจิหน้าชื่อ
- [ ] จดรายการด้วยคำค้นของหมวดนั้น → การ์ดจดสำเร็จขึ้น "🐱 ชื่อหมวด" และรายการในหน้า "รายการ" มีอีโมจิหน้าหมวด
- [ ] กดช่อง "พี่ฮูก" → "หมวดรายจ่าย" → ปุ่มหมวดนั้นมีอีโมจิ กดแล้วช่องพิมพ์เติม **ชื่อหมวดล้วน** (ไม่มีอีโมจิในช่องพิมพ์) พิมพ์เลขต่อแล้วจดเข้าหมวดถูก
- [ ] `สรุปหมวด` และ `ล่าสุด` โชว์อีโมจิของหมวดตัวเอง; หมวดมาตรฐานไม่มีอีโมจิและไม่มีชื่อไอคอนหลุดออกมา
- [ ] แก้หมวด → ล้างอีโมจิ → กลับเป็นไม่มีอีโมจิ; พิมพ์ข้อความหลายตัวในช่องอีโมจิ → ขึ้น "ใส่ได้เป็นอีโมจิตัวเดียวเท่านั้นนะ"
- [ ] Free: "เพิ่มหมวด" ขึ้นหน้าล็อก; หมวดของตัวเองที่มีอยู่ เปิดแก้ไขแล้วช่องถูกปิด ลบได้ และซ่อน/เรียงยังได้; หมวดมาตรฐานแก้คำค้นได้ตามเดิม

## 0.29) AI Insight (เฉพาะ Elite — **รัน migration 0018 ก่อน**)

- [ ] พิมพ์ `วิเคราะห์` → การ์ด AI Insight มีข้อสังเกต 2–4 ข้อ (ตัวเลข ฿/% ต้องตรงกับ `เทียบเดือน` และ `สรุปหมวด`) และคำแนะนำ 1 ข้อ พร้อมข้อความ "สร้างโดย AI ... ไม่ใช่คำแนะนำทางการเงินส่วนบุคคล"
- [ ] ข้อสังเกตระดับรายการ เช่น "ชานม ใช้ไป ฿… (n ครั้ง) เพิ่มขึ้น …%" ถูกต้องเมื่อเทียบกับรายการที่จดจริง
- [ ] ไม่มีข้อสังเกตที่ตัวเลขแปลกหรือไม่ตรงกับข้อมูล, ไม่มีคำแนะนำเรื่องลงทุน
- [ ] ปิด/ถอด API key ของ AI แล้วลองใหม่ → ยังได้การ์ดที่เป็นข้อสังเกตจากตัวเลข (ไม่มีข้อความ "สร้างโดย AI")
- [ ] กดซ้ำเกิน 5 ครั้งในวันเดียว → บอกว่าครบจำนวนแล้ว
- [ ] ผู้ใช้ Elite ที่เปิด "สรุปอัตโนมัติรายเดือน": ถึงวันเริ่มรอบงบ 09:00 ได้การ์ดสรุป + การ์ด AI Insight ต่อท้าย (สั่งรัน workflow `cron.yml` เพื่อทดลองได้) ส่วน Pro ได้การ์ดสรุปอย่างเดียว
- [ ] บัญชี Free/Pro พิมพ์ `วิเคราะห์` → ได้ข้อความชวนอัปเกรด Elite; ปุ่มลัด "🧠 วิเคราะห์" ใต้การ์ดสรุปทำงาน
- [ ] ดูต้นทุน AI ที่ Google AI Studio / OpenAI usage และ log `insight_failed` ใน Cloudflare

## 0.30) พยากรณ์ปลายเดือน (เฉพาะ Elite — ใช้แผนทดลอง Elite ได้ — **รัน migration 0017 ก่อน**)

- [ ] พิมพ์ `พยากรณ์` → การ์ด "พยากรณ์เงินปลายรอบ": คาดสิ้นรอบเหลือ (ตัวใหญ่ เขียว/แดง), เหลือตอนนี้ (ตรงกับ "เหลือ" ใน `สรุปเดือนนี้`), ใช้จ่ายทั่วไปต่อวัน, วันที่เหลือ
- [ ] ลองคำนวณมือ: (เหลือตอนนี้) − (ใช้จ่ายทั่วไปต่อวัน × วันที่เหลือ) ± รายการประจำที่จะมา = ตัวเลข "คาดสิ้นรอบ"
- [ ] ถ้าเงินไม่พอถึงสิ้นรอบ มีบรรทัด "เงินจะหมดประมาณ <วันที่> (อีก n วัน)" ถ้าพอ ขึ้น "เงินพอใช้ไปถึงสิ้นรอบ"
- [ ] ตั้งรายการประจำ (เช่น เงินเดือนเข้าวันที่ 25 และค่าผ่อนวันที่ 28) → ปรากฏใน "รายการประจำที่กำลังมา" และวันเงินหมดขยับตาม
- [ ] รายการที่เกิดจากกฎประจำที่จดไปแล้ว (เช่น ค่าเน็ตที่ตัดแล้ว) ไม่ทำให้ "ใช้จ่ายทั่วไปต่อวัน" สูงเกินจริง
- [ ] ผ่านไป 10 วันขึ้นไป มีบรรทัด "ถ้าใช้จ่ายเท่า 7 วันล่าสุด"; ตั้งงบรวมไว้ (โหมดงบรวม) → มีบรรทัดงบรวม
- [ ] ต้นรอบ/ข้อมูลน้อย → มีคำเตือน "ข้อมูลยังน้อย"
- [ ] ปุ่มลัด "🔮 พยากรณ์" ใต้การ์ดสรุป ส่งคำสั่งให้เอง; บัญชี Free/Pro ได้ข้อความชวนอัปเกรด Elite

## 0.31) สิทธิ์ส่งออกไฟล์และหน้าวิเคราะห์ (Pro ขึ้นไป)

- [ ] บัญชี Free: เมนู "วิเคราะห์" แสดงหน้าล็อก "กราฟและตารางวิเคราะห์สำหรับแผน Pro" มีปุ่มไปหน้าอัปเกรด และบอกคำสั่งสรุปในแชท
- [ ] บัญชี Free: หน้ารายการ กดไอคอนส่งออก → เห็นคำอธิบายและปุ่มไปหน้าอัปเกรด ไม่มีปุ่มดาวน์โหลด
- [ ] บัญชี Free: การ์ด `สรุปหมวด` ไม่มีปุ่ม "ดูกราฟในแอป"
- [ ] บัญชี Pro/Elite: หน้าวิเคราะห์เห็นกราฟแท่ง/โดนัท และส่งออก CSV/Excel ได้ตามเดิม
- [ ] หลังกดแลกวัน Pro ด้วยเหรียญสะสม (หรือทดลองฟรี) แล้วกลับมาหน้าเดิม → ปลดล็อกทันที

## 0.32) สรุปรายปี และ เทียบเดือนรายหมวด (Pro ขึ้นไป)

- [ ] พิมพ์ `สรุปปี` → การ์ดปีนี้ (พ.ศ.) รายรับ/รายจ่าย/เหลือ ตัวเลขตรงกับผลรวมของหน้าวิเคราะห์ แถบรายเดือนมีเฉพาะเดือนที่ผ่านมาถึงเดือนนี้
- [ ] การ์ดมีบรรทัดเทียบ % กับปีก่อน "ช่วงวันที่เดียวกัน" (ถ้าปีก่อนมีรายจ่าย)
- [ ] `สรุปปีที่แล้ว` และ `สรุปปี 2568` ได้การ์ดทั้งปี 12 เดือน; `สรุปปี 2030` / `สรุปปี 2010` → บอกว่าปีไม่ถูกต้อง
- [ ] พิมพ์ `เทียบเดือน` → การ์ดเขียนช่วงวันที่ทั้งสองฝั่งชัดเจน (เช่น 1 ต.ค. – 17 ต.ค. เทียบ 1 ก.ย. – 17 ก.ย.) แต่ละหมวดมี ▲ แดง / ▼ เขียว และ % หมวดใหม่ขึ้น "ใหม่"
- [ ] ตัวเลขรายหมวดของ `เทียบเดือน` รวมแล้วเท่ากับแถว "รายจ่ายรวม" และตรงกับ `สรุปหมวด` ของช่วงเดียวกัน
- [ ] ปุ่มลัด 📈 เทียบเดือน และ 🗓️ ทั้งปี ใต้การ์ด `สรุปเดือนนี้` ส่งคำสั่งให้เอง
- [ ] บัญชี Free พิมพ์ทั้งสองคำสั่ง → ได้ข้อความชวนอัปเกรด

## 0.33) ล่าสุด และ สรุปหมวด (ทุกแพ็กเกจ)

- [ ] พิมพ์ `ล่าสุด` → การ์ด 5 รายการล่าสุด (ชื่อ ยอด +/- หมวด วันเวลา) เรียงใหม่สุดก่อน ไม่มีรายการที่ลบแล้ว ตรงกับหน้าสรุปใน LIFF
- [ ] พิมพ์ `สรุปหมวด` → การ์ดรายจ่ายแยกหมวดของรอบงบนี้ มียอด % และแถบ รวม % ได้ 100 พอดี ยอดรวมตรงกับ "สรุปเดือนนี้"
- [ ] ถ้ามีเกิน 8 หมวด → บรรทัดสุดท้ายเป็น "อื่นๆ (n หมวด)"
- [ ] กดปุ่ม "ดูกราฟในแอป" / "ดูทั้งหมดในแอป" เปิดหน้าที่ถูกต้อง
- [ ] ใต้การ์ด `สรุปวันนี้` / `สรุปเดือนนี้` มีปุ่มลัด 📆 ช่วงวันเอง · 📊 ตามหมวด · 🕘 ล่าสุด กด 📊 และ 🕘 ส่งคำสั่งให้เอง
- [ ] ยังไม่มีรายการ/รายจ่าย → ได้ข้อความสั้นๆ

## 0.34) ค้นหาพร้อมยอดรวม (Pro ขึ้นไป — **รัน migration 0016 ก่อน**)

- [ ] พิมพ์ `ค้นหา กาแฟ` → การ์ดผลการค้นหา: รายรับ/รายจ่าย/สุทธิ/จำนวน และ 5 รายการล่าสุดที่ตรง ตัวเลขตรงกับที่ค้นเองในหน้ารายการ
- [ ] พิมพ์ `ค้นหา #ปาร์ตี้` (รายการที่ติดแท็กไว้) → ยอดรวมเฉพาะรายการที่มีแท็กนั้น
- [ ] กด "ดูทั้งหมดในแอป" → เปิดหน้ารายการ ช่องค้นหามีคำเดิมอยู่แล้ว และมีแถบยอดรวมของผลค้น
- [ ] ค้นสิ่งที่ไม่มี → ได้ข้อความ "ไม่พบรายการที่ตรงกัน"
- [ ] พิมพ์ `ค้นหา` เฉยๆ → บอกวิธีใช้
- [ ] ค้นด้วย `50%` หรือ `_` → ไม่ทำงานเป็นตัวแทนตัวอักษร (ไม่เจอทุกรายการ)
- [ ] บัญชี Free: `ค้นหา กาแฟ` ได้ข้อความชวนอัปเกรด ส่วนช่องค้นหาในหน้ารายการยังใช้ได้แต่ไม่มีแถบยอดรวม

## 0.35) สรุปช่วงวันเอง (Pro ขึ้นไป)

- [ ] ใต้การ์ด `สรุปวันนี้` / `สรุปเดือนนี้` มีปุ่มลัด "📆 ช่วงวันเอง" กดแล้วเลือกวันเริ่ม → วันสิ้นสุด (ปฏิทินที่สองเริ่มจากวันเริ่มถึงวันนี้) → ได้การ์ด "สรุปช่วงที่เลือก" บอกวันที่และจำนวนวัน
- [ ] พิมพ์ `สรุป 1/10 ถึง 15/10` ได้การ์ดเดียวกัน ตัวเลขตรงกับรายการในหน้ารายการช่วงเดียวกัน (ลองรอบตัดบัตร เช่น `สรุป 25/9 - 24/10`)
- [ ] ลองช่วงข้ามปี `สรุป 25/12 - 24/1` ได้ 31 วัน
- [ ] การ์ดมีบรรทัดเทียบ % กับ "ช่วงก่อนหน้า" ที่ยาวเท่ากัน (ถ้าช่วงก่อนหน้ามีรายจ่าย)
- [ ] `สรุป 1/10` (ไม่มีวันจบ) → บอกวิธีพิมพ์ ช่วงเกิน 366 วัน → บอกเหตุผล
- [ ] บัญชี Free พิมพ์หรือกดปุ่ม → ได้ข้อความชวนอัปเกรด ไม่เห็นปฏิทิน

## 0.4) จดย้อนหลังด้วยปฏิทิน (Pro ขึ้นไป)

- [ ] กดช่อง "พี่ฮูก" → ใต้การ์ดมีปุ่มลัด "📅 จดย้อนหลัง" กดแล้วบอทตอบพร้อมปุ่ม "เลือกวันที่"
- [ ] กด "เลือกวันที่" → ปฏิทินของ LINE เปิด เลือกได้ถึงวันนี้ ย้อนได้ 1 ปี (วันในอนาคตเลือกไม่ได้)
- [ ] เลือกวัน เช่น 12 ต.ค. → บอทบอกวันที่แบบ พ.ศ. กดปุ่ม "พิมพ์รายการ" → คีย์บอร์ดเปิดและมี `12/10/2026 ` อยู่ในช่องพิมพ์แล้ว
- [ ] พิมพ์ต่อ `กาแฟ 60` ส่ง → จดเป็นวันที่ 12 ต.ค. (เช็กในหน้ารายการ)
- [ ] บัญชี Free กด "📅 จดย้อนหลัง" → ได้ข้อความชวนอัปเกรด ไม่เห็นปฏิทิน
- [ ] ถ้าแอป LINE รุ่นเก่าไม่เติมข้อความให้ ให้จดอาการไว้ (พิมพ์ `12/10 กาแฟ 60` เองก็ใช้ได้)

- [ ] ปุ่ม "↩ ยกเลิก": คนจดกดลบได้; เพื่อนอีกคนกด → บอกว่าลบได้เฉพาะของตัวเอง; เจ้าของสมุดกดลบของใครก็ได้
- [ ] `ลบล่าสุด` ลบเฉพาะรายการล่าสุด**ของคนที่พิมพ์**
- [ ] พิมพ์คำสั่งส่วนตัวในกลุ่ม (`กระเป๋า` `หนี้` `เป้าหมาย` `บิล`) → บอทเงียบ ไม่เปิดเผยข้อมูลส่วนตัว และยอดส่วนตัวของแต่ละคน**ไม่เปลี่ยน**
- [ ] สมาชิกที่ไม่เคยเพิ่มบอทเป็นเพื่อน/ไม่ยอมรับข้อกำหนด พิมพ์ `จด ...` → บอทบอกให้เพิ่มบอทเป็นเพื่อนก่อน (ถ้าไม่มี userId) หรือจดได้ปกติถ้ามี
- [ ] เจ้าของพิมพ์ `ปิดสมุดกลุ่ม` → ปิด; คนอื่นพิมพ์ → บอกว่าเฉพาะเจ้าของ; `เปิดสมุดกลุ่ม` ใหม่ → ข้อมูลเก่ายังอยู่
- [ ] เตะบอทออกจากกลุ่มแล้วดึงกลับ → ต้องเปิดสมุดใหม่ (ข้อมูลเก่ายังอยู่)
- [ ] (ถ้าทำได้) ทดสอบหลังแผน Elite ของเจ้าของหมดอายุ: จดไม่ได้ แต่ `สรุป` ยังใช้ได้

## 5.5) หารค่าใช้จ่ายทริปในกลุ่ม (ต้องรัน migration 0028 ก่อน; ใช้กลุ่มทดสอบที่เปิดสมุดแล้วจากข้อ 5.3 และมีเพื่อนอย่างน้อย 3 คน)

- [ ] คนไหนก็พิมพ์ `เริ่มทริป เที่ยวทดสอบ` ได้ → การ์ดมีปุ่ม "🙋 ร่วมทริป"; พิมพ์ซ้ำตอนมีทริปอยู่ → บอกว่ามีทริปเปิดอยู่แล้ว
- [ ] เพื่อนอีก 2 คนกดปุ่มหรือพิมพ์ `ร่วมทริป` → บอกจำนวนคนในทริป; `ทริป` แสดงรายชื่อ
- [ ] ก. จด `จด ข้าวเย็น 900` → การ์ดบอก "หาร 3 คน คนละ ฿300" และจ่ายโดยใคร
- [ ] ข. อีกคน `จด แท็กซี่ 200 หาร <ชื่อตัวเอง> <ชื่อเพื่อน>` → หารเฉพาะสองคนนั้น; `จด ค่าห้อง 3000 ไม่หาร <ชื่อใครสักคน>` → หารที่เหลือ
- [ ] ชื่อไม่ตรง (`หาร นก`) → ไม่จด บอกว่าไม่รู้จักชื่อนั้น; `จด ข้าว 100 หาร <ชื่อ>` นอกทริป → บอกให้เริ่มทริปก่อน
- [ ] ยอดหารไม่ลงตัว (`จด ขนม 100` หาร 3 คน) การ์ดบอก "คนละประมาณ ฿33.34" และ `สรุปทริป` รวมส่วนแบ่งแล้วตรงกับยอดจริง
- [ ] `สรุปทริป` → ยอดรวม รายคน (จ่ายไป/ส่วนของตัวเอง/ได้คืน-ต้องจ่าย) และ "ใครต้องโอนให้ใคร" คำนวณมือแล้วตรง
- [ ] สกุลเงิน: `จด ราเมน 1500 JPY` ในทริป → แปลงเป็นบาท (การ์ดแสดงยอดเดิมและอัตรา) แล้วเอาไปหารด้วย; `จด ข้าว 50000 VND` → ไม่รองรับ
- [ ] คนที่ไม่ได้กดร่วมทริปแต่พิมพ์ `จด` ในทริป → ถูกเพิ่มเข้าทริปอัตโนมัติ
- [ ] `ลบล่าสุด` / ปุ่มยกเลิก ทำให้ `สรุปทริป` เปลี่ยนตาม
- [ ] คนอื่น (ไม่ใช่คนเริ่มทริป/เจ้าของสมุด) พิมพ์ `จบทริป` → ถูกปฏิเสธ; คนเริ่มทริปหรือเจ้าของพิมพ์ → ปิดทริปพร้อมการ์ดสรุป
- [ ] หลังจบทริป `จด` ใหม่ไม่ผูกทริป; `สรุปทริป` ยังดูทริปที่เพิ่งจบ; `ทริปเก่า` แสดงรายการ
- [ ] เริ่มทริปใหม่ได้หลังจบแล้ว และรายการของทริปเก่าไม่ปน

## 5.2) กระเป๋าเงินร่วมกับแฟน (ต้องรัน migration 0029 ก่อน) — ต้องใช้บัญชี LINE **สองบัญชี** (A = เจ้าของ Pro ขึ้นไป, B = แฟน แผนไหนก็ได้)

- [ ] A (Free) ลองสร้างกระเป๋าร่วม → ไม่มีตัวเลือก/ถูกบอกให้อัปเกรด
- [ ] A (Pro) หน้ากระเป๋าเงิน → เพิ่มกระเป๋า → ติ๊ก "กระเป๋าร่วมกับคนอื่น" ชื่อ "กองกลาง" ใส่ยอดตั้งต้น → ขึ้นป้าย "👥 ร่วมกัน 1 คน"; สร้างใบที่สองไม่ได้ (Pro มี 1 ใบ)
- [ ] A กด "ชวนเข้ากระเป๋า" → ได้รหัส 6 หลัก (หรือพิมพ์ `เชิญ กองกลาง` ในแชท)
- [ ] B พิมพ์รหัสผิด → ข้อความ "ไม่พบรหัสนี้"; พิมพ์ `ร่วมกระเป๋า <รหัสถูก>` → ร่วมสำเร็จ กระเป๋า "กองกลาง" ขึ้นในรายการของ B
- [ ] ใช้รหัสเดิมซ้ำ (คนที่สาม C) → "ถูกใช้ไปแล้ว"; A ขอรหัสใหม่ให้ C ตอนที่ Pro มีครบ 2 คนแล้ว → บอกว่าเต็ม (Elite เชิญได้ถึง 10)
- [ ] A จด `ข้าวเย็น 300 @กองกลาง` และ B จด `ค่าน้ำมัน 500 @กองกลาง` → ทั้งสองคนเห็นยอดคงเหลือกระเป๋า "กองกลาง" เท่ากัน (ยอดตั้งต้น − 800)
- [ ] หน้ารายการ กรองกระเป๋า "กองกลาง" → เห็นรายการของทั้งคู่พร้อมชื่อ "คุณ"/ชื่อแฟน; รายการของแฟนไม่มีปุ่มแก้/ลบ; ไม่กรองกระเป๋า → เห็นเฉพาะของตัวเอง
- [ ] `สรุปเดือนนี้` ของ A นับเฉพาะรายจ่ายที่ A จดเอง (ไม่รวมของ B) และของ B ก็เช่นกัน
- [ ] **ความเป็นส่วนตัว:** B ไม่เห็นกระเป๋าส่วนตัว/หนี้/เป้าหมาย/บิลของ A (และกลับกัน) ในแชทและหน้าเว็บ
- [ ] โอน/หนี้ที่เลือกกระเป๋าร่วม → ปฏิเสธพร้อมข้อความ "กระเป๋าร่วมใช้ได้เฉพาะรายรับ/รายจ่าย"; ไม่มีกระเป๋าร่วมในรายการตอนโอนที่หน้าเว็บ
- [ ] B กด "ออกจากกระเป๋านี้" (หรือ `ออกจากกระเป๋า กองกลาง`) → ออกได้ รายการที่ B เคยจดยังอยู่ในกระเป๋า ยอดไม่เปลี่ยน; A เอา B ออกได้เองจากรายชื่อสมาชิก; A ออกเองไม่ได้
- [ ] A ลบกระเป๋าร่วม → ทั้งสองคนไม่เห็นกระเป๋านั้นแล้ว รายการของแต่ละคนยังอยู่
- [ ] ผู้ใช้ใหม่ที่ยังไม่มีกระเป๋าเลย พิมพ์ `ร่วมกระเป๋า <รหัส>` เป็นอย่างแรก → ต่อมาจดรายการปกติได้ และมีกระเป๋า "เงินสด" เป็นกระเป๋าหลักของตัวเอง

## 6.2) ล้างข้อมูลเพื่อเริ่มต้นใหม่ (ต้องรัน migration 0030 ก่อน) — ใช้บัญชีทดสอบ ไม่ใช่บัญชีจริง

- [ ] เตรียม: มีรายการหลายเดือน (อย่างน้อย 2 เดือน) มีกระเป๋า 2 ใบ มียอดตั้งต้น 1 ใบ มีโอน/หนี้/ยอดหยอดกระปุก อย่างละ 1–2 รายการ มีรูปแนบ 1 รูป (และถ้าเป็นไปได้มีกระเป๋าร่วมที่จดรายการไว้)
- [ ] ตั้งค่า → "ล้างประวัติการเงินทั้งหมด" → แสดงจำนวนรายการรับ/จ่าย โอน หนี้ หยอดกระปุก ไฟล์ ตรงกับที่มี และแจ้งจำนวนรายการในกระเป๋าร่วมที่จะ**ไม่**ถูกลบ
- [ ] ช่อง "คงยอดเงินปัจจุบัน..." ติ๊กอยู่ตั้งแต่แรก; ยังไม่ได้พิมพ์ยืนยัน = ปุ่มลบกดไม่ได้; พิมพ์ผิด (เช่น "ล้าง") = ยังกดไม่ได้
- [ ] พิมพ์ "ล้างประวัติ" แล้วลบ (ติ๊กคงยอด) → รายการ/โอน/หนี้/ยอดหยอดกระปุกหาย; **ยอดเงินของแต่ละกระเป๋าเท่าเดิม** (ยอดตั้งต้นใหม่ = ยอดก่อนลบ) ; หน้าสรุปเป็นศูนย์
- [ ] ยังอยู่ครบ: แผน (Pro/Elite และวันหมดอายุ), การตั้งค่า, หมวดของตัวเอง, งบ, กระเป๋า, กระปุก (ยอดสะสม 0), บิล, รายการประจำ, เหรียญสะสม
- [ ] ทำซ้ำกับบัญชีทดสอบอีกอัน แต่เอาติ๊ก "คงยอดเงิน" ออก → ยอดกระเป๋ากลับไปเท่ายอดตั้งต้นเดิม
- [ ] รายการที่ลงในกระเป๋าร่วมยังอยู่ และอีกฝ่ายยังเห็นเหมือนเดิม
- [ ] ส่งสลิปใบเดิมที่เคยอ่านแล้วกลับเข้ามา → อ่านและจดได้อีก (ไม่ใช่ "เคยจดไว้แล้ว") แต่โควตาสลิปรายเดือนไม่ถูกคืน
- [ ] "ลบเฉพาะเดือน" → เลือกเดือนจากรายการ (เห็นเฉพาะเดือนที่มีข้อมูล) → ตัวเลขตรง → ต้องพิมพ์ "ลบเดือน ต.ค. 2569" (ตามเดือนที่เลือก) พิมพ์เดือนผิดกดไม่ได้
- [ ] ลบแล้วเฉพาะเดือนนั้นหาย เดือนอื่นอยู่ครบ รายการวันที่ 1 และวันสุดท้ายของเดือนถูกนับถูกเดือน; หนี้/กระปุก/ยอดตั้งต้นไม่ถูกแตะ
- [ ] ใช้งานต่อได้ปกติหลังล้าง จดรายการใหม่ได้ ไม่ต้องตั้งค่าใหม่

## 6.4) ธีมสีการ์ดและนิสัยบอท (ต้องรัน migration 0032 ก่อน)

- [ ] Free: การ์ด "ธีมการ์ดและนิสัยบอท" มีข้อความ "สำหรับแผน Pro"; เลือกได้เฉพาะ "เขียวมิ้นต์" และ "สุภาพ"
- [ ] Pro: เลือก "ฟ้าทะเล" → ตัวอย่างการ์ดเปลี่ยนสี ขึ้น "บันทึกแล้ว"; จดรายการในแชท → การ์ดยืนยันเป็นโทนฟ้า (ป้ายรายจ่ายยังแดง รายรับยังเขียว)
- [ ] ลองทุกธีม (ชมพูพีช, ม่วงลาเวนเดอร์, ดำกลางคืน) กับการ์ดสรุป/งบ/หนี้/บิล/เป้าหมาย: ตัวอักษรอ่านออกทุกใบ โดยเฉพาะธีมดำ (หัวการ์ดดำ ตัวอักษรขาว)
- [ ] นิสัย "เพื่อนสนิท" / "ชมเยอะ": จดรายการแล้วมีประโยคสั้น ๆ ต่อท้ายหนึ่งบรรทัด (เปลี่ยนไปมาแต่ละครั้ง); ถ้าจดแล้วเกินงบจะไม่มีประโยคชมซ้อนกับคำเตือน
- [ ] นิสัย "ดุหน่อย": จดปกติยังนิ่ง แต่ตอนงบถึง 80% / เกิน 100% หรือเกินงบรายวัน บอทดุ (ไม่หยาบ)
- [ ] ตัวเลขและป้ายในการ์ดไม่เปลี่ยนตามนิสัย (ยอดเงิน หมวด วันที่ เหมือนเดิม)
- [ ] กลับมาเลือก "เขียวมิ้นต์" + "สุภาพ" → ทุกอย่างเหมือนเดิมทุกประการ
- [ ] (ถ้าทดลองได้) แผนหมดอายุ → การ์ดและโทนกลับเป็นค่าเดิม แต่การ์ดตั้งค่ายังจำที่เคยเลือก; ต่ออายุแล้วกลับมา
- [ ] การ์ดในกลุ่ม LINE และข้อความเตือน/สรุปอัตโนมัติ ยังเป็นธีมกลาง (ตามขอบเขต)

## 7) จุดขายในแชท (Upsell) (ต้องรัน migration 0033 ก่อน)

- [ ] Free: พิมพ์ "เมื่อวาน ข้าวผัด 60" → ไม่มีรายการถูกจด; ได้การ์ดอัปเกรด มีราคา ฿59/เดือน ปุ่ม "ทดลองใช้ฟรี 7 วัน" "ดูแผนและอัปเกรด" "จดเป็นวันนี้แทน"
- [ ] กด "จดเป็นวันนี้แทน" → จด "ข้าวผัด 60" เป็นวันนี้
- [ ] พิมพ์ "เมื่อวาน ..." อีกครั้งในวันเดียวกัน → ได้ข้อความสั้น ไม่ใช่การ์ดซ้ำ; วันถัดไปได้การ์ดอีกครั้ง
- [ ] กด "ทดลองใช้ฟรี 7 วัน" → บอทแจ้งเริ่มทดลอง Pro; หน้าตั้งค่าขึ้นแผน Pro; จดย้อนหลังได้; กดซ้ำ/เคยทดลองแล้ว → ข้อความว่าเริ่มไม่ได้ และการ์ดรอบหลังไม่มีปุ่มทดลอง
- [ ] Free (บัญชีใหม่) ส่งรูปสลิปใบแรก → อ่านให้ตามปกติ มีข้อความ "สลิปที่อ่านให้ฟรี 1 ใบ" ต่อท้าย; ยืนยัน/แก้หมวด/ยกเลิกทำงานได้
- [ ] ส่งรูปที่ไม่ใช่สลิปเป็นใบแรก → บอทบอกว่าไม่ใช่สลิป และสิทธิ์ฟรียังอยู่ (ส่งสลิปจริงอีกครั้งยังอ่านให้)
- [ ] ส่งสลิปใบถัดไป → ได้การ์ดชวนอัปเกรด (Pro 30 ใบ/เดือน, Elite ไม่จำกัด) ไม่มีการอ่าน
- [ ] Pro/Elite: ไม่เห็นการ์ดชวนอัปเกรดในทุกกรณี

## 8) หน้าอัปเกรด: ทำอะไรได้บ้าง

- [ ] ตาราง "ทำอะไรได้บ้าง?" มีคอลัมน์ Free / Pro / Elite แต่ละแถวชื่อสั้นพร้อมไอคอน ไม่มีแถบเลื่อนซ้าย-ขวา อ่านง่ายที่ 360px
- [ ] แผนที่ทำได้มีเครื่องหมายถูก แผนที่ไม่มีเป็นขีด (เช่น จดย้อนหลัง: Free ขีด, Pro/Elite ถูก; จดด้วยเสียง: ถูกเฉพาะ Elite)
- [ ] ข้อจำกัดแสดงเป็นข้อความในช่อง (สลิป "ลองฟรี 1 ใบ" / "5 ใบ/เดือน" / "ไม่จำกัด", กระเป๋า "1 ใบ" / "5 ใบ" / "ไม่จำกัด") ไม่ล้นช่อง

## 20) โทนสีเขียวพาสเทล ทั้งหน้าสรุป วิเคราะห์ และหมวด/งบ + หน้าหมวด/งบแบบใหม่ (ไม่ต้องรัน migration)

- [ ] แตะการ์ดหมวด → แผ่น "แก้ไขหมวด": ชื่อ (หมวดมาตรฐานแก้ชื่อไม่ได้) งบ + ปุ่มลัด +฿500/+฿1,000/+฿3,000/+฿5,000 (บวกจากยอดที่กรอก) กราฟประวัติ 6 เดือน + เฉลี่ย (Pro ขึ้นไป) คำค้น อีโมจิ/สี (หมวดของฉัน) สวิตช์ "ซ่อนหมวดนี้" และปุ่มลบ (หมวดของฉัน) · บันทึกแล้วการ์ดอัปเดต · Free: ช่องงบเป็นล็อกอ่านอย่างเดียว · ไม่มีสกรอลล์ข้างที่ 360px

## 21) หน้ารายการแบบใหม่ + ส่งออก Excel/CSV/PDF เลือกคอลัมน์ ZIP รูปสลิป (ไม่ต้องรัน migration)

- [ ] โทนเขียวพาสเทลเหมือนหน้าสรุป · หัวหน้า "รายการบันทึก" · การ์ด "ช่วงเวลาที่เลือก" (เริ่มที่ "ทุกช่วงเวลา") · กล่องกรอง (ทั้งหมด/รายจ่าย/รายรับ + ปุ่มส่งออก + ช่องค้นหา + แถบหมวดเลื่อนข้างข้าม + เลือกกระเป๋าถ้ามีหลายใบ) · ปุ่ม "เลือกหลายรายการ" และ "ตั้งรายการจดประจำ" · ปุ่ม + มุมขวาล่างเหนือแถบเมนู ไม่ทับรายการสุดท้าย (เลื่อนลงสุดแล้วกดได้) · ไม่มีสกรอลล์ข้างที่ 360px
- [ ] รายการจัดกลุ่มตามวัน หัวกลุ่มมีวันที่ ("วันนี้"/"เมื่อวาน") และยอดรวมของวัน (รายรับ−รายจ่ายของรายการที่โหลดแล้ว สีแดงถ้าติดลบ เขียวถ้าบวก) · เลื่อนลงกด "โหลดเพิ่ม" ยอดของวันที่ตกขอบหน้าเพิ่มขึ้นตามจริง
- [ ] การ์ดรายการ: ไอคอน/อีโมจิหมวด ชื่อ เวลา "น." ป้ายหมวด ป้ายกระเป๋า ไอคอนเล็กบอกว่ามีรูปแนบ/สลิป แท็ก สกุลเงินเดิม ชื่อผู้เขียน (กระเป๋าร่วม) ยอดสีตามประเภท · แตะการ์ด → แผ่นแก้ไข มีปุ่ม "ดูสลิป" (ถ้ามี) และ "ลบรายการนี้" (ถามยืนยัน) · รายการของสมาชิกคนอื่นในกระเป๋าร่วมแตะไม่ได้
- [ ] แตะ "ช่วงเวลาที่เลือก" → ปฏิทิน: เดือนก่อน/ถัดไป · แตะวันแรกแล้วแตะวันสุดท้าย (แตะวันก่อนวันแรก = เริ่มใหม่) · ทางลัด เดือนนี้/สัปดาห์นี้/เดือนที่แล้ว/ทั้งหมด · ตกลง → รายการตามช่วง (ปีพุทธศักราช) · "ทั้งหมด" ล้างช่วง
- [ ] แถบหมวด: แตะหมวดเพื่อกรอง (แตะซ้ำยกเลิก) · เปลี่ยนประเภท (รายจ่าย/รายรับ) แล้วหมวดที่เลือกถูกล้างและแถบเปลี่ยนตามประเภท · ค้นหา/กระเป๋า/ช่วงเวลา/หมวด ใช้ร่วมกันได้
- [ ] เลือกหลายรายการ: แถบเขียวด้านบนนับจำนวน ย้ายหมวด ลบ ยกเลิก · ปุ่ม + หายระหว่างเลือก
- [ ] ปุ่ม "ตั้งรายการจดประจำ" → หน้าตั้งค่า เลื่อนมาที่การ์ดรายการประจำ
- [ ] ปุ่มส่งออก → แผ่น "ส่งออกข้อมูลรายการ" (Pro ขึ้นไป; Free เห็นหน้าล็อก): เลือก Excel/CSV/PDF · ตัวกรองที่ใช้อยู่ (ช่วงเวลา ประเภท หมวด) ส่งออกตามนี้จริง · ติ๊กคอลัมน์ (วันที่&เวลา ชื่อรายการ จำนวนเงิน ประเภท หมวดหมู่ กระเป๋า ที่มา สกุลเงินเดิม) ต้องเหลืออย่างน้อย 1 · ไฟล์ที่ได้มีเฉพาะคอลัมน์ที่ติ๊ก (ลองเปิด CSV/Excel/PDF)
- [ ] PDF: เปิดในเบราว์เซอร์/แอปไฟล์ของเครื่อง ภาษาไทยอ่านได้ไม่ซ้อน มีหัวสีเขียว ช่วงเวลา การ์ดยอดรวมรับ/จ่าย/คงเหลือ รายจ่ายตามหมวดพร้อมแถบ ตารางรายการ (ชื่อยาวถูกตัดด้วย …) และเลขหน้า · ช่วงที่มีรายการมากกว่า 2,000 รายการ ตารางตัดที่ 2,000 พร้อมข้อความ ยอดรวมยังนับครบ
- [ ] เปิดสวิตช์ "รวมไฟล์รูปสลิป / ใบเสร็จ" (Pro ขึ้นไป) → ได้ไฟล์ .zip ที่ในนั้นมีไฟล์ข้อมูลที่เลือก และโฟลเดอร์ "รูปสลิปและใบเสร็จ" รูปสลิปกับรูปแนบเรียงเลขชื่อตามวันที่/ชื่อรายการ · แนบได้สูงสุด 150 รูป/40 MB ถ้าเกินมีไฟล์ "อ่านก่อน.txt" บอกจำนวนที่ไม่ได้แนบ · ลิงก์ส่งออกหมดอายุใน 2 นาที
- [ ] หน้าสรุป: รายการล่าสุดเป็นการ์ดแบบใหม่ (แสดงวันที่ + เวลา) ไม่มีแถบสีเขียวมิ้นต์ข้างรายการแล้ว

## 22) หน้าตั้งค่าแบบใหม่ + โทนเขียวพาสเทลทั้งแอป (ไม่ต้องรัน migration)

- [ ] ทุกหน้าในแอป (สรุป วิเคราะห์ หมวด/งบ รายการ ตั้งค่า กระเป๋า เป้าหมาย บิล อัปเกรด ฯลฯ) เป็นโทนเขียวพาสเทล พื้นครีม · โหมดมืดเป็นเขียวเข้ม อ่านชัด · หน้า /pay, นโยบาย, ข้อกำหนดยังเป็นโทนเดิม (อยู่นอกแอป)
- [ ] ตั้งค่า: การ์ดโปรไฟล์ (รูป ชื่อ ป้ายแผน "ใช้ได้ถึง …" โควตาสลิป ช่องเหรียญสะสม/จดต่อเนื่อง กล่องแลกวัน ปุ่มดูแผน ลิงก์ "ประวัติการชำระเงิน: n รายการ") · การ์ดยืนยันหลังจด · รอบงบ (มีบรรทัดอธิบาย) · ไม่มีสกรอลล์ข้างที่ 360px
- [ ] "การแจ้งเตือนและสรุปอัตโนมัติ" เป็นการ์ดเดียว: เตือนจดประจำวัน (เปิดแล้วมีช่องเวลาที่เตือน) สรุปรายสัปดาห์ สรุปรายเดือน · Free เห็นสวิตช์ปิดและป้าย Pro · เปิด/ปิดแล้วบันทึกทันที

- [ ] กลุ่มเมนู: กระเป๋าเงิน / เป้าหมายการออม / เตือนจ่ายบิล ไปหน้าของมัน · "รายการประจำ" (มีป้าย + เพิ่ม) และ "จัดหมวดด้วยความจำ" เปิดเป็นแผ่นล่างที่เพิ่ม/หยุด/ลบ/ดูความจำได้ครบเหมือนเดิม · เปิด /settings#recurring (จากปุ่ม "ตั้งรายการจดประจำ" หน้ารายการ) แผ่นรายการประจำเปิดเอง
